# 提交

负责把一次请求落到一次运行上并记下尝试，结果未知时按请求号找回；不负责结束运行，也不负责请求的内容。

## 需求

每次落到运行上的提交都留下一条尝试记录（来源：示例需求），由 ``Submit`Submit`` 走通。

## 为什么

开始、找回与记下尝试收成一个连接点 ``Submit`Submit``，因为 ``Run`Start`` 结果未知之后要用 ``Run`Status`` 找回，这依赖两者共享的运行表 ``Run`Runs``：这个连接面只在这里接一次。``Report`` 这样的上层单元只区分 ``Submit`SubmitOutcome`` 的两支，不处理结果未知，也不 import ``Attempt``。
